# Lossless File Compressor (Huffman Coding & Greedy Min-Heap)

## Core DSA Concepts
- Greedy Algorithms, Binary Trees, PriorityQueue (Min-Heap), Prefix-Free Bit Encoding

## Complexity Analysis
- **Time Complexity:** `O(N + K log K) where K is unique characters`
- **Space Complexity:** `O(K) tree and lookup map`

## How to Compile & Run
```bash
javac HuffmanFileCompressor.java
java HuffmanFileCompressor
```
