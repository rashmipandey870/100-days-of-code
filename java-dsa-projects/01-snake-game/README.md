# Snake Game Engine (Arrays, Deque & HashSet Collision)

## Core DSA Concepts
- 2D Grid Arrays, ArrayDeque (O(1) Head/Tail Ops), HashSet (O(1) Collision Detection)

## Complexity Analysis
- **Time Complexity:** `O(1) per move`
- **Space Complexity:** `O(W * H)`

## How to Compile & Run
```bash
javac SnakeGameEngine.java
java SnakeGameEngine
```
