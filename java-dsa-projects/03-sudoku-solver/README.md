# Sudoku Solver Engine (Backtracking & Recursion)

## Core DSA Concepts
- Recursion, Backtracking State Space Search, Constraint Satisfaction Pruning

## Complexity Analysis
- **Time Complexity:** `O(9^m) where m is empty cells`
- **Space Complexity:** `O(1) auxiliary board space`

## How to Compile & Run
```bash
javac SudokuSolverEngine.java
java SudokuSolverEngine
```
