# Cash Flow Minimizer / Splitwise Engine (Graphs & Heaps)

## Core DSA Concepts
- Directed Graph Net Balance + Max-Heap / Min-Heap PriorityQueues (Greedy Settlement)

## Complexity Analysis
- **Time Complexity:** `O(N log N)`
- **Space Complexity:** `O(N)`

## How to Compile & Run
```bash
javac CashFlowMinimizer.java
java CashFlowMinimizer
```
